# Sources

The editions KĀLA cites. Every `source` slug used in `content/` must be listed here with its licence.
See [CONTENT_GUIDE.md](CONTENT_GUIDE.md) §4 for how to cite.

## Licence rules (as of October 2026)

| Jurisdiction | Public domain when                            |
| ------------ | --------------------------------------------- |
| USA          | first published before 1 January 1931         |
| UK / EU      | author died before 1 January 1956 (life + 70) |
| India        | author died before 1 January 1966 (life + 60) |

- `public_domain`: PD in all three. May be quoted word for word, with a locator.
- `cited_only`: still in copyright somewhere. Cite by locator; never reproduce.
- We use only the **original editions** listed. Later revised or annotated reprints may be in copyright.

## Verification status

- **Verified**: confirmed against a catalogue, Wikipedia or a scan (sources noted).
- **To check**: from standard reference knowledge, not yet confirmed online. Every edition below was
  first published before 1931, so the USA verdict holds either way. Before a source is used in
  `content/`, confirm the translator's death date and add a scan link here.

## Gaps

- **No public-domain English translation found** of the Shiva, Linga, Vayu, Brahmanda or Padma
  Puranas (the Motilal Banarsidass series, 1970s onward, is in copyright). Shaiva genealogies in
  Phase 1 must rest on the Mahabharata, Ramayana, Vishnu, Bhagavata, Markandeya and Devi Bhagavata
  Puranas, and Kalidasa. Logged as OQ-008.
- Nasadiya and Purusha Suktas: Griffith (`griffith-rigveda`) and Muir (`muir-original-sanskrit-texts`).
